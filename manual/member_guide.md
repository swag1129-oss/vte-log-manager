# VTE Log 폰 앱 안내 (A222 멤버용)

증착 로그를 폰에서 바로 기록하는 웹앱이에요. 기록은 랩 Dropbox `VTE_MANAGER` 폴더에 PC 매니저와 같은 엑셀 양식으로 저장돼요. PC 매니저로 열어도 똑같이 보여요.

## 1. 설치 (한 번만)
- 주소: https://swag1129-oss.github.io/vte-log-manager/
- 아이폰: **Safari**로 열기 → 공유 버튼 → **홈 화면에 추가**
- 안드로이드: **Chrome**으로 열기 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- 홈 화면의 **VTE Log** 아이콘으로 실행해요

## 2. 첫 실행
1. **Dropbox 로그인**: 랩 공용 Dropbox 계정으로 로그인해요. 계정 정보는 관리자에게 따로 받아주세요.
2. **작성자 이름** 입력: 저장하는 로그에 이 이름이 남아요. 설정에서 바꿀 수 있어요.
3. 자동으로 로그 목록을 받아와요. 처음엔 1~2분 걸릴 수 있어요.

## 3. 기록하기
1. **기록** 탭 → 일반증착/툴링 새 로그, 또는 프리셋에서 시작
2. 레이어 카드
   - 재료 칸에서 `CBP_50_O-2` 같은 항목을 고르면 소스·TF·최신 ratio가 자동으로 들어가요
   - 파란 박스에 **목표 두께(nm)**를 넣으면 옆에 **모니터에서 올릴 두께**가 크게 떠요
   - 박스 아래에 어느 날짜 calibration을 썼는지 나와요
3. 증착하면서 **▶ 시작 / ■ 끝**을 누르면 시각이 기록돼요. 압력·레이트·파워·온도는 왼쪽이 시작, 오른쪽이 끝이에요
   - 흐린 글씨 `지난 4.9`는 같은 재료·소스로 마지막에 증착했을 때 값이에요
   - **파워/온도** 글자를 누르면 최근 5번 기록을 볼 수 있어요
4. 공증착은 **+ 공증착 추가** → 합계 두께와 재료별 부피비(%)를 넣으면 재료마다 모니터 두께가 나와요. 레이트를 넣으면 실제 부피비도 계산해 줘요
5. 입력하는 동안 폰에 자동 저장돼요. 앱이 꺼져도 이어서 쓸 수 있어요
6. 다 끝나면 **Dropbox에 저장**

## 4. 알아둘 것
- **인터넷이 끊겨도** 저장을 누르면 폰에 보관했다가 연결되면 자동으로 올려요 (위쪽 "업로드 대기")
- **새 버전**이 나오면 위에 "새 버전이 있어요 · 적용"이 떠요. 적용을 누르면 돼요. 작성 중인 기록은 그대로 남아요
- 저장한 로그는 **로그** 탭에서 보고, 수정·삭제할 수 있어요. 다른 사람이 먼저 고친 파일은 덮어쓰지 않고 새 파일로 저장해요
- 삭제한 파일은 Dropbox 휴지통에서 복구할 수 있어요
- 우측 위 **구조** 그림을 누르면 접고 펼 수 있고, 층을 누르면 그 카드로 이동해요

## 5. PC (Windows)
- `VTE_MANAGER/distribution/windows`의 `VTE_Log_Manager_v11_Windows.zip`을 풀고 `INSTALL_WINDOWS.cmd` 실행
- 앱에서 **폴더 선택** → Dropbox의 `VTE_MANAGER` 폴더 선택
- 폰에서 저장한 로그·프리셋이 그대로 보여요

문제가 생기면 화면을 캡처해서 #thermalevaporator-log 채널에 올려주세요.
